VOC · 数智化企划设计中心

voc.pythonanywhere.com
核心中枢系统，统一入口与数据汇聚点。涵盖消费者洞察、竞品分析、产品规划管理、灵感库、色彩调研、知识库RAG等24个API模块，是全业务链路的编排引擎。

AMZN · 亚马逊数据爬虫

amzn.pythonanywhere.com
市场情报采集引擎，自动爬取亚马逊Best Sellers热卖榜与New Releases新品榜。支持多类目配置、Playwright智能爬取、Supabase云端存储，为企划决策提供数据弹药。
Best SellersNew ReleasesPlaywrightSupabase

COLOR · 品牌色彩库

color.pythonanywhere.com
设计标准化体系，包含2914色LASEN品牌色彩库、KMeans聚类色彩分析、AI图片理解多维表格、调色工具与色彩网络分析，确保色彩决策有据可依。
2914色体系KMeans聚类AI图片理解调色工具

YFB · 利润测算与货盘工具

yfb.pythonanywhere.com
商业决策引擎，精准测算FBA全链路成本与利润率。覆盖产品成本、头程费用、FBA配送费、佣金、广告比、退货率等全费用项，输出毛利率与净利润率，支撑货盘规划与首单决策。
利润计算器FBA费用货盘规划净利润率

LASEN · 中台产品表现分析

lasen.pythonanywhere.com
运营反馈仪表盘，自动爬取中台产品表现数据。提供评分预警报表、评分追踪跟进、爆款监控、面料-评分关联分析、评分波动分析、问题店铺识别，GitHub Actions每周自动执行。

Chapter 05

集成度与缺口分析

当前五大系统间存在三大核心数据断点，导致数据无法闭环流动。识别断点、评估缺口是架构升级的第一步。

系统集成度矩阵

集成关系当前状态实现方式评估
VOC → YFB 已集成反向代理 /api/yfb/单向代理，数据未双向同步
AMZN → VOC 弱集成数据独立存储爬虫数据未自动流入VOC竞品分析
COLOR → VOC 弱集成模块存在但数据未打通2914色色彩库与VOC色彩模块未同步
LASEN → VOC 未集成完全独立部署运营数据无法回流企划驱动迭代
AMZN → LASEN 弱集成ASIN可关联但未自动化排名数据与评分数据未自动关联

断点 1：AMZN → VOC

爬虫采集的市场数据（竞品排名、价格、评分）无法自动进入VOC的竞品分析和趋势模块，企划决策缺乏实时市场数据支撑。

集成度 15%

断点 2：LASEN → VOC

已上架产品的评分、销量表现无法回流到VOC的产品详情页，无法支撑"运营反馈驱动产品迭代"的闭环决策。

集成度 0%

断点 3：COLOR → VOC

2914色品牌色彩体系与VOC的色彩调研/色彩库模块未数据打通，设计标准化无法在企划流程中直接落地。

集成度 20%

Chapter 06

实施路径与优先级

按照"数据打通→流程串联→智能升级→平台统一"的四阶段递进策略，逐步实现全数智化企划研发平台。

P1

Phase 1 · 数据打通

最高优先级 · 消除数据孤岛
1.1

AMZN爬虫数据 → VOC竞品分析模块自动同步

爬虫采集的竞品排名、价格、评分数据自动写入VOC数据库，驱动竞品分析和趋势洞察模块。

价值：市场数据驱动企划决策复杂度：中
1.2

LASEN评分/销量数据 → VOC产品详情页回流

已上架产品的评分、销量、MAG/TAC/COT等运营数据回流至VOC产品详情页，支撑迭代决策。

价值：运营反馈驱动产品迭代复杂度：中
1.3

COLOR色彩库 → VOC色彩调研/色彩库模块打通

2914色LASEN品牌色彩体系数据同步至VOC，色彩调研可直接引用品牌标准色。

价值：设计标准化落地复杂度：低
P2

Phase 2 · 流程串联

高优先级 · 消除线下环节
2.1

产品详情页内嵌YFB利润计算器

在VOC产品详情页的设计成本Tab中嵌入利润计算器，实现企划→定价一体化操作。

价值：企划定价比价一体化复杂度：低
2.2

需求池 → 产品规划 → 进度跟踪全流程在线化

打通需求池到产品创建的流程，需求评审通过后自动生成产品卡片并进入规划管理。

价值：消除线下流转环节复杂度：中
2.3

评分预警 → 产品负责人自动通知

LASEN评分预警触发时，自动推送通知至VOC中对应产品的负责人，形成闭环运营反馈。

价值：闭环运营反馈复杂度：低
P3

Phase 3 · 智能升级

中优先级 · AI辅助决策
3.1

基于AMZN数据的品类机会自动推荐

利用排名变化率、新品增速、空白价格带等指标，自动识别品类机会并推送至需求池。

价值：AI辅助企划决策复杂度：高
3.2

基于LASEN数据的爆款预测与补货建议

结合销量趋势、评分变化、季节因子等数据，预测爆款概率并生成补货建议。

价值：AI辅助运营决策复杂度：高
3.3

RAG知识库接入全业务数据

将市场数据、产品数据、运营数据纳入RAG知识库，实现AI问答覆盖全业务场景。

价值：AI问答覆盖全场景复杂度：中
3.4

COLOR图片理解 → 自动色彩方案推荐

灵感图片上传后自动提取主色，匹配品牌色彩体系并推荐色彩方案。

价值：AI辅助设计决策复杂度：中
P4

Phase 4 · 平台统一

长期目标 · 一体化平台
4.1

统一数据库（SQLite → PostgreSQL/Supabase）

将5个系统的数据存储统一至PostgreSQL/Supabase，消除数据孤岛，保障数据一致性。

价值：数据一致性保障复杂度：高
4.2

统一前端架构（VOC为基座，模块化接入）

以VOC的React+TS+AntD为前端基座，其他系统以模块/微前端方式接入，统一用户体验。

价值：用户体验一致性复杂度：高
4.3

统一部署与DevOps

Docker容器化部署，CI/CD流水线，统一监控与日志，提升运维效率。

价值：运维效率提升复杂度：中

Summary

核心结论

核心优势

业务闭环完整 — 从市场洞察到运营反馈，5大系统覆盖企划研发核心链路
VOC中枢定位清晰 — 24个API模块构建完整企划研发能力矩阵
色彩体系差异化 — 2914色LASEN品牌色彩体系是极具竞争力的设计资产
自动化能力扎实 — 爬虫自动化、GitHub Actions定时任务已落地
已有集成意识 — VOC→YFB反向代理说明统一入口架构思维

核心挑战

数据孤岛 — 5个系统4种数据存储，三大核心断点未打通
技术栈碎片 — 3种前端+2种后端，维护和集成成本高
缺少统一身份 — 5个独立域名/入口，用户体验割裂
供应链未覆盖 — 面料采购→生产→物流环节缺失
多平台未扩展 — 仅覆盖Amazon，未覆盖TikTok/TEMU等
以VOC为统一平台基座，以"数据打通"为第一优先级
将AMZN / COLOR / YFB / LASEN从"独立系统"升级为"VOC的能力模块"
实现 一个入口 · 一套数据 · 一个闭环 的全数智化企划研发平台
